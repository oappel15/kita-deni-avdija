# Kita · Deni Avdija web deck

An English HTML slide deck (18 slides) about Israeli NBA player Deni Avdija, for classrooms and general audiences.

- `index.html`: the deck. Use the arrow keys, Space, a click, or a swipe to move. F = fullscreen, N = speaker notes, P = presenter view.
- `style.css` and `deck.js`: the styles and the navigation.
- `assets/`: photos from Wikimedia Commons (CC BY-SA). Attribution is on the Sources slide.

Static site with no build step, deployed on Vercel from `main`. Made by Kita.
